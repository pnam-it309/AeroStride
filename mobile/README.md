## 💻 Hướng dẫn phát triển (Development)

### 1. Cài đặt thư viện
```bash
npm install
```

### 2. Chạy ứng dụng môi trường Dev
```bash
npx expo start
```

### 3. Build APK mới qua EAS CLI
```bash
# Đăng nhập Expo EAS
eas login

# Build APK (preview profile)
eas build --platform android --profile preview
```
